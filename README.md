## Para comçar

Primeiro instale as dependências do projeto.
```bash
npm install
# ou use yarn, pnpm ou bun
```

Segundo, rode o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.


Não tem login com base de dados, então usar este [mock](src/data/users.ts) de usuários para fazer login
